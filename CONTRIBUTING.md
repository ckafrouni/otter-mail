# Contributing

Thanks for helping with Otter Mail. Setup is in [docs/development.md](docs/development.md).

- Open an issue first for anything bigger than a bug fix, so we can agree on the approach.
- Keep pull requests small and focused; one change per PR.
- Run `pnpm typecheck`, `pnpm lint` and `pnpm fmt` before pushing. CI runs the same checks.
- For UI changes, include before/after screenshots, and a short video for motion or interaction.
- Match the code around you: naming, comment density, and idioms. `AGENTS.md` describes how the
  app is put together.
